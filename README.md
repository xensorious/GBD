# The Cinder Warden — downloads

Minecraft Java Edition **1.20.1**, Forge **47.4.28**, Java **17**.

Download `cinderwarden-1.0.0.jar` and place it in your Minecraft installation's
`mods` folder. Alternatively, download the ZIP and extract the JAR first.

The boss has 100 HP and zero armor. Attacks: 6 HP cleave, two 4 HP ember bolts,
and a telegraphed 10 HP slam. Its spawn egg is in the Creative Spawn Eggs tab;
there are no natural spawning or world-generation hooks.

This download is the exact artifact built and tested in the cloud workspace:
17 Forge Game Tests passed, and an actual Minecraft client was used to inspect
combat, rendering, screenshots, and software-renderer performance. A Hard-mode
unarmored player went from 20 to 10 HP after the slam.

This branch distributes the tested binaries. It does not replace the main
branch or claim that the implementation source is committed on main.
